# Сайт DBGD

## Что где лежит

```
dbgd-site/
├── main.html          Главная
├── goods.html         Товары
├── services.html      Услуги
├── order.html         Заказ (звонок + индивидуальный заказ)
├── korzina.html       Корзина и оформление
├── Contacts.html      Контакты
├── style.css          Все стили
├── cart.js            Корзина, промокоды, история, отправка заявок
├── logo.png           Логотип в шапке
├── favicon.png        Иконка вкладки браузера
├── og-image.png       Превью при отправке ссылки в мессенджер
├── plan.jpg           Картинка товара «Программа Планы»
├── monobank-banner.jpg  Баннер банки для донатов
├── monobank-qr.png    Отдельный QR (запасной, сейчас не используется)
└── api/
    └── send-order.js  Серверная отправка заявок в Telegram
```

## Перед публикацией

1. **Отзовите старый токен бота.** @BotFather → `/revoke` → выберите бота.
   Старый токен лежал в открытом виде в коде и мог утечь.
2. Получите новый токен и свой `chat_id`
   (напишите боту, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).

## Публикация на Vercel

1. Залейте всю папку в репозиторий на github.com.
2. На vercel.com: Add New → Project → выберите репозиторий.
3. В Environment Variables добавьте:
   - `TELEGRAM_BOT_TOKEN` — новый токен
   - `TELEGRAM_CHAT_ID` — ваш chat_id
4. Deploy.

Токен живёт только в настройках Vercel и в код не попадает.

## Проверка после публикации

Откройте страницу «Заказ» на живом адресе и отправьте заявку себе.
Локально через двойной клик по файлу (`file://`) отправка работать не будет —
нужен адрес с `http`.

## Промокоды

Список задан в начале `cart.js`, в объекте `PROMO_CODES`:

- `WELCOME10` — минус 10%, без ограничений
- `DBGD15` — минус 15% при заказе от 1000 грн
- `MINUS50` — минус 50 грн при заказе от 300 грн

Чтобы добавить свой, допишите строку по образцу.
`type: 'percent'` — скидка в процентах, `type: 'fixed'` — в гривнах.

## Доставка и оплата

Способы заданы в `cart.js` (`DELIVERY_OPTIONS`, `PAYMENT_OPTIONS`)
и продублированы списком в `korzina.html`.
Меняете цену доставки — поправьте в обоих местах.

## Лимиты корзины

- от 1 до 20 штук одной позиции (`MAX_QTY`)
- не больше 30 разных позиций (`MAX_POSITIONS`)

## Что стоит доделать дальше

- Товаров пока один — добавьте карточки в `goods.html` по образцу
- Текст на главной стоит вычитать, там есть опечатки
- `<marquee>` — устаревший тег, со временем заменить на CSS-анимацию
- Раздел «Хронология» на главной пустой
