## Админ-панель (добавление товаров без кода)

Страница `admin.html` доступна только тому аккаунту, чей email указан
в переменной окружения `ADMIN_EMAIL`. Добавьте её в Vercel рядом
с остальными (Settings → Environments → добавить переменную):

- `ADMIN_EMAIL` — например, `dbgd2026onecompany@gmail.com`

Товары хранятся в той же базе Vercel KV, что и аккаунты — под ключом `products`.
`goods.html` подгружает их оттуда автоматически через `GET /api/products`,
поэтому список товаров теперь не в HTML, а в базе — весь код руками трогать не нужно.

**Про картинки:** при добавлении товара в поле «Имя файла картинки» указывается
только имя файла (например `plan.jpg`), а сам файл нужно заранее загрузить
в репозиторий на GitHub (Add file → Upload files), в ту же папку, где лежит `main.html`.
Полноценной загрузки картинок прямо из админ-панели пока нет.

## Авторизация: что нужно настроить

Регистрация и вход работают через email + пароль с подтверждением почты.
Для этого нужны два сервиса (у обоих есть бесплатный тариф):

1. **Resend** (resend.com) — отправка писем с подтверждением.
   Зарегистрируйтесь, создайте API-ключ (раздел API Keys).
   Можно сразу слать с тестового адреса `onboarding@resend.dev`,
   свой домен подключать не обязательно.
2. **Vercel KV** — хранилище аккаунтов (email, хэш пароля, статус подтверждения).
   В панели Vercel: вкладка Storage → Create Database → KV,
   подключите её к проекту — переменные окружения добавятся автоматически.

В Vercel → Project Settings → Environment Variables добавьте:

- `RESEND_API_KEY` — ключ из Resend
- `SESSION_SECRET` — любая длинная случайная строка (для подписи cookie входа)
- `EMAIL_FROM` — необязательно, по умолчанию `DBGD <onboarding@resend.dev>`

После добавления переменных — Redeploy проекта.

Пароли хранятся не в открытом виде, а как соль + хэш (scrypt).
Сессия входа — подписанная cookie на 30 дней, срок и подпись проверяются на сервере.

## Перед публикацией

1. **Отзовите старый токен бота.** @BotFather → `/revoke` → выберите бота.
   Старый токен лежал в открытом виде в коде и мог утечь.
2. Получите новый токен и свой `chat_id`
   (напишите боту, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).

## Публикация на Vercel

1. Залейте всю папку в репозиторий на github.com.
2. На vercel.com: Add New → Project → выберите репозиторий.
3. В Environment Variables добавьте:
   - `TELEGRAM_BOT_TOKEN` — новый токен
   - `TELEGRAM_CHAT_ID` — ваш chat_id
4. Deploy.

Токен живёт только в настройках Vercel и в код не попадает.

## Проверка после публикации

Откройте страницу «Заказ» на живом адресе и отправьте заявку себе.
Локально через двойной клик по файлу (`file://`) отправка работать не будет —
нужен адрес с `http`.

## Промокоды

Список задан в начале `cart.js`, в объекте `PROMO_CODES`:

- `WELCOME10` — минус 10%, без ограничений
- `DBGD15` — минус 15% при заказе от 1000 грн
- `MINUS50` — минус 50 грн при заказе от 300 грн

Чтобы добавить свой, допишите строку по образцу.
`type: 'percent'` — скидка в процентах, `type: 'fixed'` — в гривнах.

## Доставка и оплата

Способы заданы в `cart.js` (`DELIVERY_OPTIONS`, `PAYMENT_OPTIONS`)
и продублированы списком в `korzina.html`.
Меняете цену доставки — поправьте в обоих местах.

## Лимиты корзины

- от 1 до 20 штук одной позиции (`MAX_QTY`)
- не больше 30 разных позиций (`MAX_POSITIONS`)

## Что стоит доделать дальше
